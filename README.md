# SMS Spam Detection Using Machine Learning

## Project Overview
This project uses Machine Learning to classify SMS messages as Spam or Normal.

## Dataset
The dataset contains 5,572 SMS messages:
- Normal messages: 4,825
- Spam messages: 747

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Algorithm
Multinomial Naive Bayes

## Methodology
1. Load the dataset.
2. Explore and visualize the data.
3. Split data into training and testing sets.
4. Convert text into numerical features using TF-IDF.
5. Train the Machine Learning model.
6. Evaluate model performance.
7. Predict Spam or Normal messages.

## How to Run
Open `Untitled0.ipynb` in Google Colab and run the cells in order.
